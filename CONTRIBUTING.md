# Contributing

Use small changes with a test that demonstrates the behavior. Keep AI/model integrations behind the depth interface, keep the native bridge narrow, and never weaken the Comfort Guard to make a demo look more dramatic.

Before review, run `scripts/check.ps1`, describe any skipped media/GPU checks, list new runtime dependencies with licenses, and include before/after screenshots for UI changes. Do not commit customer media, generated depth, model weights, local paths, signing material, or secrets.
